Compatibility

The same addresses as the official Pearl Wallet.

oyster, Pearl's reference wallet, derives keys with a non-standard step. For about 1 in 100 recovery phrases, a standard BIP32 wallet shows different addresses and your coins seem to vanish.

Security

Designed so you don't have to trust us.

Akoya is built for the threats a browser wallet actually faces: malicious pages, lying servers, and tampered builds. The design is written down, and so are its limits.

Threat model Permissions Report a vulnerability
  1. Encrypted vaultYour recovery phrase is sealed with Argon2id and AES-256-GCM. It is never stored in plain text.
  2. Keys exist only while signingWhile unlocked, Akoya holds only your public key. Private keys are derived for a signature and then discarded.
  3. Password on every sendEvery send and every phrase reveal asks for your password again. An unlocked popup isn't enough.
  4. Invisible to websitesNo content scripts, no injected provider, a strict CSP. The only permission is storage, plus network access to your indexer.
  5. Doesn't trust the serverIndexer responses are validated and every address is re-derived locally. Data that doesn't match is rejected.
  6. Verifiable releasesReproducible builds with SHA-256 checksums and a signed SLSA build-provenance attestation.
Install

Up and running in a minute.

Until the Chrome Web Store listing is live, install the signed release from GitHub. Akoya is alpha and hasn't been audited yet, so start with small amounts.

  1. Download

    Get akoya-<version>.zip from the latest release and unzip it.

  2. Enable developer mode

    Open chrome://extensions and switch on Developer mode in the top right.

  3. Load unpacked

    Click Load unpacked and select the unzipped folder. Setup opens in a full tab.

Verify before you trust

The checksum must match the .sha256 file, and the attestation proves the zip was built by this repository's release workflow from the tagged commit.

# checksum must match akoya-<version>.zip.sha256
shasum -a 256 akoya-<version>.zip

# provenance: built by GitHub Actions from the tag
gh attestation verify akoya-<version>.zip \
  -R akoya-wallet/akoya-extension
Chrome Web Store: coming soon. The official extension ID will be published here and in the README. Until then, any store listing called Akoya is not ours.
Stay safe

Akoya will never ask for your recovery phrase.

Not by email, not in a DM, not on a "support" or "validation" site. Anyone who asks for it wants your PRL.

  • Official website: akoyawallet.app only.
  • Official source: github.com/akoya-wallet only.
  • Official extension ID: not published yet. Anything claiming to be Akoya in a store today is a fake.
  • Contact: contact@akoyawallet.app. We never DM first.

FAQ

Questions, answered.

Is Akoya made by Pearl Research Labs?

No. Akoya is built by PRLFlipBTC, an independent team, and is not affiliated with or endorsed by Pearl Research Labs. It is designed to be fully compatible with the official Pearl Wallet.

Is it safe to use?

Akoya is alpha software and hasn't had an independent audit yet. Please keep only small amounts in it for now. An audit is on the roadmap before 1.0, and the code is public so anyone can review it today.

Does Akoya collect any data?

No. There are no analytics, no telemetry, and no accounts. By default the extension talks only to the Blockbook indexer you choose, which, as with any light wallet, can see the addresses it's asked about. Optional features you turn on yourself (price and P&L, mining-pool stats, NOCK balance) contact those services, and never with your keys. The privacy policy lists every request.

This website runs no JavaScript, and every animation on it is plain CSS.

Does it cost anything?

Akoya is free. You pay only the network fee, which is shown before you sign. Akoya adds no fees of its own.

I forgot my password. What now?

Import the wallet again with your recovery phrase and choose a new password. There's a link for this on the unlock screen. Nobody, including us, can recover a lost phrase, so keep it written down somewhere safe and offline.

Can I move from Pearl Wallet or oyster?

Yes. Import the same recovery phrase, or an oyster hex seed, and you'll see the same addresses and balance. Both wallets can stay in use at the same time.

Which browsers are supported?

Chrome 120 and newer, plus Chromium browsers such as Brave and Edge. Firefox support is planned.
