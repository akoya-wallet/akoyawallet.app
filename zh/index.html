功能

PRL 需要的都在，多余的一概没有。

一个小而专注的钱包：持有、接收、发送 Pearl。由自己也在挖 Pearl 的人打造。

签名前完整审阅

可发送到 Taproot 或 P2MR 地址。签名前，每一个输出和准确的手续费都摆在你眼前。

带上你的助记词

导入 BIP39 助记词或 oyster hex 种子，或者一分钟新建一个钱包。

兼容性

与官方 Pearl Wallet 地址完全一致。

Pearl 的参考钱包 oyster 在派生密钥时有一个非标准步骤。大约每 100 个助记词里就有 1 个，在标准 BIP32 钱包里会得到不同的地址，看起来就像币“消失”了。

Akoya 默认复现 oyster 的行为，并用取自 Pearl 官方 Go 测试的向量锁定。标准 BIP32 仍可在「高级」中选择。

安全

设计目标：你不需要信任我们。

Akoya 针对浏览器钱包真正面对的威胁而设计：恶意网页、撒谎的服务器、被篡改的安装包。设计写在文档里，它的边界也写在里面。

威胁模型 权限说明 报告漏洞
  1. 加密保险库助记词使用 Argon2id + AES-256-GCM 加密，从不以明文保存。
  2. 私钥只在签名时存在解锁期间只保留公钥。私钥只为一次签名临时派生，用完即丢弃。
  3. 每次发送都要密码每次发送、每次查看助记词都要重新输入密码。弹窗处于解锁状态并不够。
  4. 网页看不到 Akoya没有内容脚本，不向网页注入 provider，严格 CSP。唯一的权限是 storage，外加访问你所选索引节点的网络权限。
  5. 不盲信服务器索引节点返回的数据会被校验，每个地址都在本地重新派生，对不上的数据直接丢弃。
  6. 可验证的发布可复现构建，附带 SHA-256 校验和与签名的 SLSA 构建来源证明。
安装

一分钟装好。

在 Chrome 应用商店上架之前，请从 GitHub 安装带签名证明的发布包。Akoya 目前是 Alpha 版本，尚未经过审计，请先放少量资金。

  1. 下载

    从最新发布下载 akoya-<版本>.zip 并解压。

  2. 打开开发者模式

    打开 chrome://extensions，打开右上角的「开发者模式」。

  3. 加载扩展

    点击「加载已解压的扩展程序」，选择解压后的文件夹。初始化会在完整标签页中打开。

先验证，再信任

校验和必须与 .sha256 文件一致；来源证明可以确认安装包是由本仓库的发布流程、从对应 tag 构建出来的。

# 校验和必须与 akoya-<版本>.zip.sha256 一致
shasum -a 256 akoya-<版本>.zip

# 来源证明：由 GitHub Actions 从 tag 构建
gh attestation verify akoya-<版本>.zip \
  -R akoya-wallet/akoya-extension
Chrome 应用商店：即将上架。 官方扩展 ID 会公布在这里和 README 中。在此之前，商店里任何叫 Akoya 的插件都不是我们。

常见问题

你可能想问

Akoya 是 Pearl Research Labs 做的吗？

不是。Akoya 由独立团队 PRLFlipBTC 开发，与 Pearl Research Labs 无关联，也未获其背书。它与官方 Pearl Wallet 完全兼容。

安全吗？

Akoya 目前是 Alpha 版本，尚未经过独立审计，请先只放少量资金。1.0 之前会进行审计；代码已经公开，现在任何人都可以审查。

Akoya 会收集数据吗？

不会。没有统计、没有遥测、无需账号。插件只与你选择的 Blockbook 索引节点通信；和任何轻钱包一样，该节点能看到被查询的地址。

本网站不运行任何 JavaScript，页面上的动效全部是纯 CSS。

收费吗？

免费。你只需支付网络手续费，签名前会显示。Akoya 不额外收取任何费用。

忘记密码怎么办？

用助记词重新导入钱包并设置新密码，解锁页面上就有入口。包括我们在内，任何人都无法找回丢失的助记词，请把它抄写下来，离线妥善保存。

能从 Pearl Wallet 或 oyster 迁移过来吗？

可以。导入同一个助记词或 oyster hex 种子，就能看到相同的地址和余额。两个钱包可以同时使用。

支持哪些浏览器？

Chrome 120 及以上，以及 Brave、Edge 等 Chromium 浏览器。Firefox 支持在计划中。
